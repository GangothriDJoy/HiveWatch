    Presenter notes

    HiveWatch is an SSH honeypot that changes how it looks to attackers. This page runs the whole prototype with one click.

    Step 4 is three attacks: a port scan, password guessing, and a manual login that types five commands. They come from a separate attacker machine inside a closed network.

    Two recordings are made at the same time: the honeypot's own log and a full packet capture. The Sessions page shows how they are joined.

    What the attacker sees right now

    Each run picks a new hostname and SSH version, so a scanner that fingerprinted the honeypot yesterday sees a different machine today.

        Presenter notes
    
        The honeypot knows what the attacker typed but not the network detail. The packet capture knows the traffic but not the commands. Neither is complete alone.
        
    
        The correlator joins them using source address, source port and time. Match means a session and a network conversation are the same event.
        
    
        The panel on the right lists connections that only the network recording saw, such as the port scan. That is the value of having both.
